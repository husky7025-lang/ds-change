# 결보강 시간표 자동 탐색 (GitHub Pages 정적 버전)

대전동산고 결보강(수업 교체·보강) 탐색 웹앱의 GitHub Pages용 정적 버전입니다.
서버 없이 `index.html` 하나만으로 동작합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (UI + 탐색 결과 + 계획서 인쇄) |
| `engine.js` | 탐색 엔진 (시간표 파싱·교체/보강 탐색·공동공강·시뮬레이션) |
| `timetable.csv` | 시간표 데이터 (CSV) |

## GitHub Pages 배포

1. 이 폴더의 파일들을 GitHub 저장소에 push
2. 저장소 Settings → Pages → Deploy from a branch → `main` / `/(root)` 선택
3. `https://<사용자명>.github.io/<저장소명>/` 으로 접속

## 시간표 데이터 운영

- **선생님들은 개별 업로드가 필요 없습니다.** 관리자가 저장소의 `timetable.csv`만 교체하면, 페이지 접속 시 자동으로 최신 시간표를 받아옵니다.
- 시간표가 바뀌면(학기 교체 등) GitHub에서 `timetable.csv` 파일만 덮어쓰기하면 됩니다. (`Add file` → `Upload files`에서 같은 이름으로 업로드)
- 브라우저에 저장된 이전 시간표가 새 파일을 가리지 않도록, 접속 시 해시를 비교해 변경분을 자동 갱신합니다.
- 개별 PC에서 **📁 시간표 CSV 업로드** 버튼으로 올린 파일은 해당 PC에서만 우선 적용됩니다 (테스트용).
- CSV 양식: 기존 Apps Script 버전의 시트와 동일한 레이아웃
  - 4행: C열부터 교사명
  - 5행부터: A열 요일(월~금), B열 교시(N교시), 교사별 2행(과목 행 + 교실 행) 반복
  - 한글 CSV는 EUC-KR/UTF-8 자동 판별

> 현재 포함된 `timetable.csv`는 **샘플 데이터**입니다. 실제 시간표 CSV로 교체해주세요.

## Apps Script 버전과의 차이

- ❌ **결보강대장 기능 제외**: 대장 저장/조회, 대장 반영 탐색이 없습니다. 원본 시간표 기준 정적 탐색만 수행합니다.
- ✅ 교체/보강 탐색, 공동 공강 탐색, 교체 전후 시뮬레이션, 계획서 인쇄(PDF)는 동일하게 동작합니다.
- 탐색 로직은 Apps Script 버전(fix3)과 동등성 테스트를 통과했습니다.
